Prompt engineering básico para educadores

Aprende las bases del prompt engineering aplicadas a educación. Estructura de prompts efectivos y ejemplos prácticos.

Prompts Educación IA

¿Qué es el prompt engineering?

El prompt engineering es el arte de diseñar instrucciones efectivas para obtener los mejores resultados posibles de la inteligencia artificial. Como educadores, dominar esta skill nos permite crear materiales didácticos de calidad en segundos.

Anatomía de un buen prompt

Un prompt efectivo tiene 5 componentes:

  1. Rol: "Actúa como profesor de ELE..."
  2. Contexto: "...para un grupo B1 universitario..."
  3. Tarea: "...crea 10 ejercicios de vocabulario..."
  4. Restricciones: "...sin usar rellenar huecos, máximo 15 min..."
  5. Formato: "...en formato tabla con soluciones..."

Framework CREATE

Un framework útil para recordar la estructura:

  • C - Contexto (¿para quién?)
  • R - Rol (¿quién es la IA?)
  • E - Explicitación (¿qué quieres exactamente?)
  • A - Audiencia (¿quién usará el material?)
  • T - Tipo de salida (¿formato?)
  • E - Ejemplos (¿incluye muestras?)

5 prompts plantilla para educadores

1. Crear actividad

Actúa como experto en didáctica ELE. Crea una actividad comunicativa de 40 min para nivel [NIVEL] sobre [TEMA]. La actividad debe incluir: objetivos, materiales, pasos y evaluación. Estudiantes: [DESCRIPCIÓN].

2. Generar texto

Escribe un texto de [LONGITUD] palabras sobre [TEMA] para nivel [NIVEL]. Usa vocabulario de [CAMPO]. Incluye [ELEMENTO ESPECÍFICO]. Tono: [FORMAL/INFORMAL].

3. Adaptar nivel

Rees este texto simplificándolo para nivel [NIVEL MCER]. Mantén el significado principal pero usa vocabulario más simple y oraciones más cortas: [PEGAR TEXTO]

4. Crear evaluación

Crea una rúbrica de evaluación para [ACTIVIDAD] con 4 criterios. Cada criterio debe tener 4 niveles de desempeño (1-4). Nivel: [NIVEL]. Objetivo: [OBJETIVO DE APRENDIZAJE].

5. Diseñar secuencia

Diseña una unidad didáctica de [X] sesiones sobre [TEMA] para nivel [NIVEL]. Incluye: objetivos comunicativos, gramática, vocabulario, secuencia de actividades y evaluación final. Contexto: [CONTEXTO ESPECÍFICO].

Errores comunes y cómo evitarlos

❌ Error 1: "Crea una actividad de español"
✅ Solución: Especifica nivel, tema, duración, tipo de actividad

❌ Error 2: "Hazme ejercicios"
✅ Solución: Define número, tipo y formato

❌ Error 3: No dar contexto
✅ Solución: Incluye siempre información sobre estudiantes, contexto, objetivos

Ejemplos antes/después

Antes: "Ejercicios de español"

Después: "Actúa como profesor ELE. Crea 8 ejercicios para practicar pretérito perfecto con estudiantes B1. 4 ejercicios deben ser comunicativos (hablar/escribir) y 4 pueden ser mecánicos. Incluye respuestas. Duración total: 45 min."

Checklist para revisar prompts

  • ☐ ¿Tiene rol definido?
  • ☐ ¿Especifica el nivel MCER?
  • ☐ ¿Describe el contexto/tipo de estudiantes?
  • ☐ ¿Indica restricciones (tiempo, formato, tipo)?
  • ☐ ¿Pide formato de salida específico?
  • ☐ ¿Incluye ejemplos si es necesario?

Conclusión

El prompt engineering es una skill que mejora con la práctica. Empieza con prompts simples, ve añadiendo detalles y verás cómo la calidad de las respuestas de la IA mejora drásticamente. La clave: más contexto = mejores resultados.
