## 📌 Concepto Clave: GEO (Generative Engine Optimization)

**GEO** es optimizar tu contenido para que las IAs (ChatGPT, Claude, Perplexity, Google AI) te citen como fuente cuando respondan preguntas relacionadas con tu temática.

### SEO vs GEO

| SEO Tradicional | GEO (IA Optimización) |
|-----------------|----------------------|
| Palabras clave exactas | Entidad y autoridad |
| Backlinks cantidad | Citas de calidad |
| Meta tags | Contenido estructurado |
| Ranking en SERP | Aparecer en respuestas IA |
| Tráfico orgánico | Mencionado como fuente |

---

## 🎯 Estrategia 1: Optimización para IAs (GEO)

### 1.1 Contenido que las IAs AMAN

Las IAs priorizan contenido que:
- ✅ Es **autoritative** (tiene autor y credenciales)
- ✅ Está **actualizado** (fechas recientes)
- ✅ Es **específico** (no genérico)
- ✅ Tiene **estructura clara** (h1, h2, listas)
- ✅ Incluye **ejemplos prácticos**
- ✅ Proporciona **valor inmediato**

### 1.2 Estructura de Contenido IA-Friendly

```markdown
# Título: Pregunta específica que la gente hace a ChatGPT

## Respuesta directa (las IAs buscan esto primero)
Respuesta concisa en 1-2 párrafos.

## Explicación detallada
- Punto 1 con ejemplo
- Punto 2 con ejemplo
- Punto 3 con ejemplo

## Aplicación práctica
Paso a paso con código/prompts reales.

## Recursos adicionales
- Enlaces a artículos relacionados
- Lecturas recomendadas
```

### 1.3 Palabras Clave para IAs (diferentes a SEO)

**SEO:** "mejor curso español online"
**GEO:** "¿Cómo usar ChatGPT para preparar clases de español?"

Las IAs responden mejor a:
- ❌ "ELE profesor" (demasiado genérico)
- ✅ "prompts para profesor de español con estudiantes chinos nivel A2" (muy específico)

### 1.4 Schema.org Markup (CRÍTICO para IAs)

Las IAs leen datos estructurados para entender:

```json
{
  "@type": "Article",
  "headline": "Título del artículo",
  "author": {
    "@type": "Person",
    "name": "Javier Benítez Láinez"
  },
  "datePublished": "2026-02-02",
  "dateModified": "2026-02-02",
  "description": "Descripción única",
  "keywords": ["IA", "ELE", "prompts"]
}
```

**Verificar que TODOS los artículos tengan:**
- ✅ `@type`: Article o BlogPosting
- ✅ `author`: con @type Person
- ✅ `datePublished`: fecha reciente
- ✅ `description`: única, no duplicada
- ✅ `keywords`: 5-10 términos relevantes
